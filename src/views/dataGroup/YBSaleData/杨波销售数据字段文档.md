# 杨波销售数据 - 前端接口字段文档

> 数据库: `pos` | 表前缀: `yb_` | 命名风格: 驼峰 (camelCase)

---

## 一、yb_sale_data（销售主表）

> 一笔交易一条记录，主键为 `id`

| 字段名               | 类型              | 必填   | 说明                                       | 枚举值                                                                                         |
| -------------------- | ----------------- | ------ | ------------------------------------------ | ---------------------------------------------------------------------------------------------- |
| `id`                 | number (bigint)   | **是** | 销售记录唯一 ID                            | —                                                                                              |
| `orgId`              | number (bigint)   |        | 机构(门店)ID                               | —                                                                                              |
| `orgName`            | string (100)      |        | 机构(门店)名称                             | —                                                                                              |
| `salesNo`            | string (50)       |        | 销售单号                                   | —                                                                                              |
| `tradeTime`          | string (datetime) |        | 交易(结账)时间，格式 `yyyy-MM-dd HH:mm:ss` | —                                                                                              |
| `memberId`           | number (bigint)   |        | 会员 ID，`0` 表示散客(非会员)              | —                                                                                              |
| `memName`            | string (50)       |        | 会员名称，散客时为 `null`                  | —                                                                                              |
| `memCode`            | string (50)       |        | 会员编号，散客时为 `null`                  | —                                                                                              |
| `cellPhoneNo`        | string (20)       |        | 会员手机号，散客时为 `null`                | —                                                                                              |
| `levelCode`          | string (2)        |        | 会员等级代码                               | `N` → 普通会员, `S` → 白银会员, `G` → 黄金会员, `P` → 铂金会员, `D` → 钻石会员                 |
| `beforeBalance`      | number (12,2)     |        | 交易前会员余额                             | —                                                                                              |
| `afterBalance`       | number (12,2)     |        | 交易后会员余额                             | —                                                                                              |
| `beforeUnionBalance` | number (12,2)     |        | 交易前会员联合余额(跨店)                   | —                                                                                              |
| `afterUnionBalance`  | number (12,2)     |        | 交易后会员联合余额(跨店)                   | —                                                                                              |
| `shouldAmount`       | number (12,2)     |        | 应收金额(标价总额)                         | —                                                                                              |
| `actualAmount`       | number (12,2)     |        | 实收金额(折后实际支付)                     | —                                                                                              |
| `discountAmount`     | number (12,2)     |        | 折扣金额(应收 - 实收)                      | —                                                                                              |
| `optDiscount`        | number (12,2)     |        | 优惠折扣金额                               | —                                                                                              |
| `optDisId`           | number (bigint)   |        | 优惠折扣 ID                                | —                                                                                              |
| `totalCost`          | number (12,2)     |        | 总成本                                     | —                                                                                              |
| `commissionAmount`   | number (12,2)     |        | 提成金额                                   | —                                                                                              |
| `cashPay`            | number (12,2)     |        | 现金支付金额                               | —                                                                                              |
| `memberCardPay`      | number (12,2)     |        | 会员卡(储值)支付金额                       | —                                                                                              |
| `bankCardPay`        | number (12,2)     |        | 银行卡支付金额                             | —                                                                                              |
| `wechatPay`          | number (12,2)     |        | 微信支付金额                               | —                                                                                              |
| `aliPay`             | number (12,2)     |        | 支付宝支付金额                             | —                                                                                              |
| `couponsPay`         | number (12,2)     |        | 优惠券支付金额(电子券)                     | —                                                                                              |
| `entityCouponPay`    | number (12,2)     |        | 实体优惠券支付金额                         | —                                                                                              |
| `meiTuanPay`         | number (12,2)     |        | 美团支付金额                               | —                                                                                              |
| `kouBeiPay`          | number (12,2)     |        | 口碑支付金额                               | —                                                                                              |
| `douYinPay`          | number (12,2)     |        | 抖音支付金额                               | —                                                                                              |
| `lianLianPay`        | number (12,2)     |        | 连连支付金额                               | —                                                                                              |
| `otherPay`           | number (12,2)     |        | 其他支付金额                               | —                                                                                              |
| `onlinePay`          | number (tinyint)  |        | 是否在线支付                               | `0` → 否, `1` → 是                                                                             |
| `onlinePayAmount`    | number (12,2)     |        | 在线支付金额                               | —                                                                                              |
| `payState`           | number (tinyint)  |        | 支付状态                                   | —                                                                                              |

| `createrUserId`      | number (bigint)   |        | 开单操作员 ID                              | —                                                                                              |
| `createUserName`     | string (50)       |        | 开单操作员名称                             | —                                                                                              |
| `settleUserId`       | number (bigint)   |        | 结账操作员 ID                              | —                                                                                              |
| `settleUserName`     | string (50)       |        | 结账操作员名称                             | —                                                                                              |
| `transSettleAmount`  | number (12,2)     |        | 转账结算金额                               | —                                                                                              |
| `transBrandId`       | number (bigint)   |        | 转账品牌 ID                                | —                                                                                              |
| `signBillStaffId`    | number (bigint)   |        | 签单员工 ID                                | —                                                                                              |
| `timesCardInfo`      | string (255)      |        | 次卡信息                                   | —                                                                                              |
| `batchFlag`          | string (50)       |        | 批次标记                                   | —                                                                                              |
| `batchNum`           | number (int)      |        | 批次号                                     | —                                                                                              |
| `shortDate`          | number (int)      |        | 短日期(YYMMDD 格式)                        | 如 `260417` 表示 2026 年 04 月 17 日                                                           |
| `createTime`         | string (datetime) |        | 记录创建时间                               | —                                                                                              |
| `updateTime`         | string (datetime) |        | 记录更新时间                               | —                                                                                              |
| `updateUserId`       | number (bigint)   |        | 最后更新操作员 ID                          | —                                                                                              |

| `remark`             | string (500)      |        | 备注                                       | —                                                                                              |

## 二、details 子项结构（Detail）

> 每笔交易可包含多条明细，存储在主表的 `details` JSON 字段中

| 字段名              | 类型              | 说明                                  | 枚举值                                                            |
| ------------------- | ----------------- | ------------------------------------- | ----------------------------------------------------------------- |
| `id`                | number (bigint)   | 销售明细唯一 ID                       | —                                                                 |
| `salesId`           | number (bigint)   | 关联销售主表 ID (→ `yb_sale_data.id`) | —                                                                 |
| `productId`         | number (bigint)   | 产品(项目)ID                          | —                                                                 |
| `prodCode`          | string (50)       | 产品编码                              | —                                                                 |
| `prodName`          | string (100)      | 产品名称                              | —                                                                 |
| `prodType`          | number (tinyint)  | 产品类型                              | `69` → 项目, `71` → 产品, `73` → 耗材, `75` → 疗程券, `77` → 其他 |
| `prodCost`          | number (decimal)  | 产品成本                              | —                                                                 |
| `quantity`          | number (int)      | 销售数量                              | —                                                                 |
| `standPrice`        | number (decimal)  | 标准单价(标价)                        | —                                                                 |
| `acturalPrice`      | number (decimal)  | 实际价格(折后单价)                    | —                                                                 |
| `serviceType`       | number (tinyint)  | 服务(上钟)类型                        | `89` → 轮牌, `91` → 点工, `92` → 加钟                             |
| `serviceTime`       | number (int)      | 服务时长(分钟)                        | —                                                                 |
| `serviceStart`      | string (datetime) | 服务开始时间                          | 部分记录为 `null`                                                 |
| `serviceEnd`        | string (datetime) | 服务结束时间                          | 部分记录为 `null`                                                 |
| `treatType`         | number (tinyint)  | 服务方式                              | —                                                                 |
| `serviceStaffId`    | number (bigint)   | 服务技师 ID                           | —                                                                 |
| `serviceStaffName`  | string (50)       | 服务技师名称                          | —                                                                 |
| `serviceStaffCode`  | string (50)       | 服务技师编号                          | —                                                                 |
| `bedId`             | number (bigint)   | 床位 ID                               | —                                                                 |
| `bedName`           | string (50)       | 床位名称                              | —                                                                 |
| `finPayType`        | number (tinyint)  | 财务支付类型                          | `1` → 现金, `2` → 会员卡                                          |
| `payKey`            | string (100)      | 支付标识                              | —                                                                 |
| `thirdCouponDealId` | number (bigint)   | 第三方优惠券交易 ID                   | —                                                                 |
| `packageId`         | number (bigint)   | 套餐 ID                               | —                                                                 |
| `packageAmount`     | number (decimal)  | 套餐金额                              | —                                                                 |
| `packageUuid`       | string (100)      | 套餐唯一标识                          | —                                                                 |
| `updateUser`        | number (bigint)   | 最后更新操作员 ID                     | —                                                                 |

## 三、saleMemConsumeFins 子项结构（Fin）

> 会员消费时各资产账户的扣减明细，存储在主表的 `saleMemConsumeFins` JSON 字段中

| 字段名       | 类型             | 说明               | 枚举值             |
| ------------ | ---------------- | ------------------ | ------------------ |
| `finId`      | number (bigint)  | 财务记录 ID        | —                  |
| `finNo`      | string (50)      | 财务编号(资产编号) | —                  |
| `finAmount`  | number (decimal) | 财务消费金额       | —                  |
| `tranFin`    | number (tinyint) | 是否转账           | `0` → 否, `1` → 是 |
| `finOrgId`   | number (bigint)  | 消费门店(机构)ID   | —                  |
| `finOrgName` | string (100)     | 消费门店(机构)名称 | —                  |

## 四、关联关系

```
yb_sale_data (1) ──→ (N) details         关联键: details.salesId = yb_sale_data.id
yb_sale_data (1) ──→ (N) saleMemConsumeFins  同一主记录下的财务扣减明细
```

## 五、完整枚举字典

### OrderStatus（订单状态）

| 值   | 含义         |
| ---- | ------------ |
| `37` | 已开单       |
| `39` | 已结账       |
| `41` | 已取消       |
| `43` | 已挂账(签单) |
| `45` | 已挂单       |
| `46` | 已冲正       |

### MemberLevel（会员等级）

| code (levelCode) | 含义     |
| ---------------- | -------- |
| `N`              | 普通会员 |
| `S`              | 白银会员 |
| `G`              | 黄金会员 |
| `P`              | 铂金会员 |
| `D`              | 钻石会员 |

### ProductType（产品类型）— detail.prodType

| 值   | 含义   |
| ---- | ------ |
| `69` | 项目   |
| `71` | 产品   |
| `73` | 耗材   |
| `75` | 疗程券 |
| `77` | 其他   |

### ServiceType（服务上钟类型）— detail.serviceType

| 值   | 含义 |
| ---- | ---- |
| `89` | 轮牌 |
| `91` | 点工 |
| `92` | 加钟 |

### FinPayType（财务支付类型）— detail.finPayType

| 值  | 含义   |
| --- | ------ |
| `1` | 现金   |
| `2` | 会员卡 |

### OnlinePay（是否在线支付）

| 值  | 含义 |
| --- | ---- |
| `0` | 否   |
| `1` | 是   |

### TranFin（是否转账）— fin.tranFin

| 值  | 含义 |
| --- | ---- |
| `0` | 否   |
| `1` | 是   |
