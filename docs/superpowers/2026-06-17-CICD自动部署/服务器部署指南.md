# CI/CD 自动部署 - 服务器部署指南

## 环境要求

| 软件    | 版本要求 |
| ------- | -------- |
| Node.js | v18+     |
| pnpm    | v8+      |
| Git     | 任意版本 |
| Nginx   | 任意版本 |
| PM2     | v5+      |

## 服务器信息

| 环境 | 服务器 IP      | 部署目录                    | Webhook 端口 |
| ---- | -------------- | --------------------------- | ------------ |
| 测试 | 39.107.119.113 | /www/wwwroot/front/pos-test | 54280        |
| 生产 | 82.156.232.52  | /www/wwwroot/front/pos      | 54280        |

## 部署步骤

### 1. 安装基础环境

```bash
# 安装 Node.js（如果没有）
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs

# 安装 pnpm
npm install -g pnpm

# 安装 PM2
npm install -g pm2

# 安装 Git（如果没有）
apt-get install -y git
```

### 2. 配置 SSH 密钥（私有仓库）

```bash
# 生成 SSH 密钥
ssh-keygen -t ed25519 -C "deploy@lld_cms" -f ~/.ssh/id_ed25519 -N ""

# 查看公钥
cat ~/.ssh/id_ed25519.pub
```

将公钥添加到 Gitee：

1. 复制上面输出的公钥内容
2. 登录 Gitee → 右上角头像 → 设置 → SSH 公钥
3. 粘贴公钥，点击「确定」

测试 SSH 连接：

```bash
ssh -T git@gitee.com
```

如果看到「Hi caihaocc! You've successfully authenticated」表示配置成功。

### 3. 克隆项目

```bash
# 创建项目目录
mkdir -p /opt/lld_cms
cd /opt

# 克隆代码（使用 SSH 地址）
git clone git@gitee.com:caihaocc/lld_cms.git lld_cms

# 切换到 dev 分支（测试环境）或 master 分支（生产环境）
cd lld_cms
git checkout dev   # 测试服务器
# git checkout master  # 生产服务器
```

### 4. 安装项目依赖

```bash
cd /opt/lld_cms
pnpm install
```

### 5. 创建日志目录

```bash
mkdir -p /var/log/lld_cms
```

### 6. 启动 Webhook 服务

```bash
cd /opt/lld_cms

# 启动服务
pm2 start scripts/ecosystem.config.cjs

# 查看状态
pm2 status

# 查看日志
pm2 logs lld-webhook
```

### 7. 设置开机自启

```bash
pm2 save
pm2 startup
```

### 8. 开放防火墙端口

```bash
# firewalld（CentOS/RHEL）
firewall-cmd --permanent --add-port=54280/tcp
firewall-cmd --reload

# ufw（Ubuntu/Debian）
ufw allow 54280/tcp
ufw reload

# iptables
iptables -A INPUT -p tcp --dport 54280 -j ACCEPT
```

### 9. 配置 Nginx

测试环境配置 `/etc/nginx/sites-available/pos-test`：

```nginx
server {
    listen 80;
    server_name pos-test.your-domain.com;  # 替换为实际域名

    root /www/wwwroot/front/pos-test;
    index index.html;

    # SPA 路由支持
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 代理
    location /test-api {
        proxy_pass http://localhost:8080/api;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # 静态资源缓存
    location /assets {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
```

生产环境配置 `/etc/nginx/sites-available/pos`：

```nginx
server {
    listen 80;
    server_name pos.your-domain.com;  # 替换为实际域名

    root /www/wwwroot/front/pos;
    index index.html;

    # SPA 路由支持
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 代理
    location /api {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # 静态资源缓存
    location /assets {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
```

启用配置：

```bash
# 创建软链接
ln -s /etc/nginx/sites-available/pos-test /etc/nginx/sites-enabled/
# 或
ln -s /etc/nginx/sites-available/pos /etc/nginx/sites-enabled/

# 测试配置
nginx -t

# 重载 Nginx
nginx -s reload
```

### 10. 配置 Gitee Webhook

1. 登录 Gitee，进入仓库页面
2. 点击「管理」→「WebHooks」→「添加」
3. 填写配置：

| 配置项   | 值                              |
| -------- | ------------------------------- |
| URL      | `http://服务器IP:54280/webhook` |
| 密码     | `LLD-Front-Webhook-Password`    |
| 触发事件 | Push Events                     |
| SSL 验证 | 不验证                          |

4. 点击「测试」验证是否正常

## 常用命令

```bash
# 查看 Webhook 服务状态
pm2 status

# 查看实时日志
pm2 logs lld-webhook

# 重启服务
pm2 restart lld-webhook

# 停止服务
pm2 stop lld-webhook

# 手动执行部署
cd /opt/lld_cms && bash scripts/deploy.sh test       # 测试环境
cd /opt/lld_cms && bash scripts/deploy.sh production  # 生产环境
```

## 故障排查

### 1. Webhook 服务无法启动

```bash
# 查看错误日志
pm2 logs lld-webhook --err

# 检查端口是否被占用
lsof -i :54280

# 检查 Node.js 版本
node -v
```

### 2. 部署失败

```bash
# 查看部署日志
ls -la /var/log/lld_cms/
cat /var/log/lld_cms/deploy-*.log

# 手动执行部署脚本测试
cd /opt/lld_cms
bash scripts/deploy.sh test
```

### 3. Gitee Webhook 测试失败

- 检查防火墙是否开放 54280 端口
- 检查服务器 IP 是否正确
- 检查密码是否匹配
- 查看 PM2 日志是否有请求记录

```
本地开发 → push 到 dev 分支 → 测试服务器自动部署 → 测试通过 → 合并到 master → 生产服务器自动部署
```
